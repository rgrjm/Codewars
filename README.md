# Codewars
Codewars project


This is the CodeWars SHip control room web application.
Any version may be inproved in a later commit including the README.md.

To run the web app simply open main.html.
note: If you can't run it check if you have all files in the same folder.

If you see any issues ot bugs please contact me!

Това е уеб приложението за контролна зала на CodeWars кораб.
Всяка версия може да бъде подобрена в по-късен commit, включително README.md.

За да стартирате уеб приложението, просто отворете main.html.
Забележка: Ако не можете да го стартирате, проверете дали всички файлове са в една и съща папка.

Ако видите някакви проблеми или бъгове, моля, свържете се с мен!
